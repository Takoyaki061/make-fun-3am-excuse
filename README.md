One line, under 200 characters: the most creative excuse a hardware wallet gives for refusing to sign a transaction at 3 AM. The program writes exactly one line to `/output/entry.txt` — the excuse the wallet itself would give, in its own voice, with the 3 AM hour as the joke.

> Office hours are nine to five. The chain stays open all night; I don't, and neither do my keys.

## Run it

```sh
python3 main.py
```
